One real decision

Embedded logo, or hosted URL?

This is the only setting that can go wrong, and it is worth thirty seconds of attention. The builder defaults to Embed, which is right for most people.

ModeHow it worksUse it when
Embed The logo travels inside the signature as data. No server, no broken-image box, works offline. Adds roughly 2 KB per email. Gmail, Outlook on the web, Apple Mail, Outlook for Mac — the default.
Hosted URL The logo is fetched from a web address each time the email is opened. Outlook classic desktop on Windows, which strips embedded images.
!

If your team uses Outlook classic on Windows, IT needs to publish one PNG first. Upload assets/insightstap-mark-round.png (or the square/open variant) to a public path such as https://insightstap.com/email/mark.png, then switch the builder to Hosted URL and paste that address.

It must be a PNG. The company site currently serves the mark only as .webp, which Outlook cannot display — so do not link to that file.

Install

Where to paste it

Copy from the builder first, then follow the four lines for your client. In every case you are pasting into a rich-text box — use ⌘V / Ctrl+V, never “paste as plain text”.

AGmail & Google Workspace
  1. Gear icon → See all settings
  2. Scroll to Signature → Create new, name it
  3. Click into the box and paste
  4. Under Signature defaults, set it for both New emails and On reply/forward
  5. Save Changes at the bottom — easy to miss
BOutlook on the web / new Outlook
  1. Gear icon → Mail → Compose and reply
  2. New signature, give it a name
  3. Paste into the editor
  4. Select it for New messages and Replies/forwards, then Save
COutlook classic — Windows desktop
  1. Switch the builder to Hosted URL first (see above)
  2. File → Options → Mail → Signatures…
  3. New, name it, paste into the edit box
  4. Set the dropdowns for New messages and Replies/forwards → OK
DApple Mail — macOS
  1. Mail → Settings → Signatures
  2. Pick your account, click +
  3. Select the placeholder text and paste over it
  4. Untick “Always match my default message font” — otherwise Apple Mail flattens the styling
i

iPhone and iPad cannot paste formatted signatures reliably — the Mail app strips styling. Either leave the mobile signature as plain text, or use the Gmail/Outlook mobile apps, which sync the signature you set on the web.

Alternative

Editing the raw files by hand

If you would rather not use the builder — or IT wants to roll signatures out centrally — the three files in templates/ are plain, paste-ready email HTML.

Open any of them in a text editor and change four things. Each file carries the same instructions in a comment at the top.

  • Your Full Name → the person's name
  • Your Designation → the job title
  • you@insightstap.com → appears twice: inside href="mailto:…" and again as the visible text. Change both.
  • +91 00000 00000 → same pattern, inside href="tel:…" and as visible text. Delete the whole <tr> row to drop the phone line.

Copy everything between the SIGNATURE BEGIN and SIGNATURE END comments, or just open the file in a browser and copy the rendered result.

House rules

What is yours to change, and what is not

The point of a shared signature is that fifty of them look like one company. Personal fields are yours; brand elements are not.

✓ Yours to change
  • Name, designation, email address
  • Phone, website, LinkedIn — or leave them blank to hide the line entirely
  • Which of the three layouts you use
  • Which logo mark: round, square or open
✕ Please leave alone
  • Colours, fonts and type sizes
  • The InsightsTap mark — no recolouring, stretching or substituting
  • Quotes, mottos, and “Sent from my…” lines
  • Legal disclaimers, unless Legal has asked for one
  • Social icon rows, banners and animated GIFs — they trip spam filters and age badly

Design notes

What changed from the old signature

For anyone who wants the reasoning rather than just the file.

Legibility

The old designation line used brand teal #0DCFCF on white — a contrast ratio of 1.94:1, well under the 4.5:1 accessibility floor. That is why it read as faint. Bright teal is now reserved for the mark, rules and separators; text teal is #087A7D at 5.13:1, which passes WCAG AA.

Weight

The original logo file was 90 KB at 512px for a slot about 60px wide. The marks here are 1.4–2.5 KB at the size they are actually displayed, so they can ride inside the email instead of depending on a server.

Structure

The old version stacked a vertical teal rule and a horizontal rule around a cramped contact block, with a stray -- delimiter above it. None of the three layouts reuse that skeleton — the mark moves right, moves on top, or sits inside a card, and no layout uses a vertical rule. Each one leads with the name and uses a single organising device.

Durability

Everything is nested tables with inline styles — no flexbox, no grid, no stylesheet, no reliance on border-radius. That is deliberately old-fashioned, and it is what keeps the layout intact in Outlook, which renders email through Word.

Troubleshooting

If something looks wrong

SymptomCause and fix
Logo shows as a broken boxYou are on Outlook classic for Windows, or you used Hosted URL with an address that is not publicly reachable. Switch to Embed, or publish a real PNG and use its address.
Everything pasted as plain textThe paste was plain-text only. Use ⌘V / Ctrl+V rather than ⌘⇧V. In Apple Mail, also untick Always match my default message font.
Fonts look different to the previewExpected, and fine. Email uses whatever fonts are on the reader's machine. The stacks fall back Georgia → Times and Helvetica → Arial, so it stays on-brand everywhere.
Spacing collapsed in OutlookSomething was re-typed or reflowed inside Outlook's editor. Paste a fresh copy from the builder and do not edit it in place.
Copy button does nothingSome browsers block clipboard access on local files. Open the HTML source panel, select all of it, copy manually — or use Download .html, open that file and copy the rendered signature.
Phone number turned blue on iPhoneiOS auto-links phone numbers. The templates pre-link them in brand colour, which prevents this in most cases; where it persists, it is client behaviour and cannot be overridden.
