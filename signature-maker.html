Now paste it into your email

Gmail — Settings (gear) → See all settings → General → Signature → Create new → paste → set it for New emails and On reply/forward → Save Changes at the bottom.

Outlook (web) — Settings → Mail → Compose and reply → New signature → paste → Save.

Apple Mail — Mail → Settings → Signatures → “+” → paste, then untick “Always match my default message font”.

Using Outlook on Windows? Read this first
